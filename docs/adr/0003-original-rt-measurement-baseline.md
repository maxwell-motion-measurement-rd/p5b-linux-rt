# 以未加入 ble.sh 的原始 RT 镜像作为首轮测量基准

首轮测量以原始RT Linux为标准，不加载ble.sh或额外交互增强环境。首轮固定使用已归档的原始 RT 启动包，以便后续结果可以追溯到同一环境；PREEMPT_RT 仍为项目必选条件，本期不做非 RT 对照。

原始镜像自带的 Bash 和原有登录 Shell 保留，不将排除 ble.sh 解释为卸载或替换 Bash。测量工具作为单独记录版本的临时载荷提供；需要改内核、设备树或诊断配置时另编号，不能将其结果混写为原始 RT 基准结果。此决定没有认定 ble.sh 已造成实时性能问题，其影响尚未测量。

基准身份、测量条件与结果边界见[测试方法与结果](../reports/rt-assessment-summary-20261029.md)；执行前镜像核对见[部署指南](../DEPLOY.md)。
