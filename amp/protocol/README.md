# 通信帧编码与共享槽接口

本目录已集成到 r003（本实验第3次修订的通信程序版本）／r004（本实验第4次修订的通信驱动与裸机程序版本） 驱动和裸机程序，G0—G5（G 为 Gate，表示六个验证关卡） 最小通信验证已完成。当前实现与限制见 [AMP 阶段成果](../../docs/reports/amp-stage-summary-20261030.md)；消息线格式版本为 1，与 r004 状态页版本 4 分开。

帧长 40—296 字节，小端、显式偏移：magic(0,u32)、version(4,u16)、type(6,u16)、header_len(8,u16)、payload_len(10,u16)、seq(12,u32)、session(16,u64)、epoch（通信服务状态的版本标识，服务重置时更新）(24,u64)、correlation(32,u32)、crc(36,u32)、payload(40,0—256B)。CRC（Cyclic Redundancy Check，循环冗余校验，用校验值发现消息数据损坏） 覆盖头部前36字节及有效载荷，排除CRC字段。

编码器不读写共享槽发布／确认字段。解码器只处理已复制到私有缓冲中的稳定帧；消息类型、会话／epoch、序号、重复消息及回绕处理须由上层状态机验证，不能因解码成功便接受执行。未知类型可以解码，但上层必须拒收。
